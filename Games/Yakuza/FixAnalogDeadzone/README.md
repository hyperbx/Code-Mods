# Fix Analog Deadzone
Fixes the analog sticks being too sensitive by using the original console deadzones.

## Pre-requisites
### Building
- Visual Studio 2026

### Running
- Yakuza 3 Remastered ([Steam](https://store.steampowered.com/bundle/63575/YAKUZA_Complete_Series/), [GOG](https://www.gog.com/en/game/yakuza_3_remastered))
- Yakuza 4 Remastered ([Steam](https://store.steampowered.com/app/1105500/Yakuza_4_Remastered/), [GOG](https://www.gog.com/en/game/yakuza_4_remastered))
- Yakuza 5 Remastered ([Steam](https://store.steampowered.com/app/1105510/Yakuza_5_Remastered/), [GOG](https://www.gog.com/en/game/yakuza_5_remastered))
- [Shin Ryu Mod Manager](https://www.nexusmods.com/site/mods/743)
