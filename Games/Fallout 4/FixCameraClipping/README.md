# Fix Camera Clipping
Fixes the camera clipping through geometry in first-person by adjusting its near distance to account for the field of view.

## Pre-requisites
### Building
- Visual Studio 2026

### Running
- Fallout 4
- [Fallout 4 Script Extender](https://f4se.silverlock.org/)
