# [Tails' Dash Rings in Stages](https://gamebanana.com/mods/294538)
Replaces all dash rings with the ones that appear in Tails' missions.

## Pre-requisites
### Building
- Visual Studio 2026

### Running
- [Sonic Generations](https://store.steampowered.com/app/71340/Sonic_Generations_Collection/) (2011)
- [Hedge Mod Manager](https://github.com/thesupersonic16/HedgeModManager/releases)
